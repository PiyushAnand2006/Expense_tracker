# Design

## Style Direction
- Minimal, flat productivity UI
- Trustworthy, calm, data-first presentation
- Consistent interaction feedback without decoration-heavy effects

## Color System
- Primary: blue scale
- Surfaces: neutral slate scale
- Feedback: red for errors
- Charts: consistent categorical palette

## Typography
- Font family: Inter
- Base size: 16px
- Headings: semibold/bold
- Numeric data: tabular figures

## Spacing & Layout
- 4px base unit
- Consistent card padding and section spacing
- Responsive breakpoints using Tailwind defaults
- Content max-width container on large screens

## Components
- Cards for grouped content
- Form inputs with visible labels and clear focus states
- Buttons with min touch target sizing
- Tables with readable density and action buttons
- Charts with legends, gridlines, and accessible contrast

## Accessibility
- Visible focus rings
- ARIA labels for icon-only actions
- Color not used as the only signal
- Support for reduced motion where applicable
